# テスト仕様書: AI要約・音声文字起こしWebアプリケーション

機能検証を目的としたテスト仕様書です。

---

## 🖥️想定環境

### ブラウザ

- Google Chrome（推奨）、Mozilla Firefox、Safari 等のモダンブラウザ
- マイク利用権限を許可できる状態

## 💼準備

1. **Ollama の起動と言語モデル**:

```bash
ollama serve
ollama pull qwen3.5:0.8b
```

2. **Flask開発サーバの起動**:

```bash
pip install -r backend/requirements.txt
python backend/app.py
```

3. **文字起こしのためのテスト用音声ファイル**

## 🎯テスト対象

- **フロントエンド**: `frontend/`
  - `HomeView.js` / `HomeView.html`（テキスト入力、文字数カウンタ、サンプル文章挿入、マイク音声録音、音声波形、音声ファイル選択/D＆D、文字起こし、モデル選択、要約スタイル選択と詳細Popover、要約実行・中断、プレビュー/生テキスト表示切替、Markdown/テキスト/PDF保存、クリップボードコピー）
  - `HistoryView.js` / `HistoryView.html`（履歴一覧表示、履歴復元、処理中排他制御バナー、個別削除モーダル、一括削除モーダル）
  - `AboutView.js` / `AboutView.html`（アプリ概要、使用OSSライブラリ一覧テーブル表示）
  - `AppSidebar.js` / `AppSidebar.html`（[+新規要約]ボタン、画面ナビゲーション、モバイル対応Offcanvasドロワー）
  - `AppToast.js`（トースト通知の表示・自動消去）
  - 各種サービス層（`api.js`, `audio.js`, `storage.js`, `download.js`, `visualizer.js`, `templateLoader.js`）
- **バックエンド**: `backend/app.py`
  - `POST /api/transcribe`: 音声ファイルの文字起こし
  - `POST /api/summarize`: テキスト要約
  - `POST /api/submit`: 要約送信
  - `GET /api/models`: 利用可能なOllamaモデル一覧取得
  - `GET /api/summary-types`: 定義済み要約形式一覧取得
  - `GET /`: `/static/index.html` へリダイレクト
- **外部依存**:
  - ローカル LLM: Ollama
  - 音声認識: faster-whisper
- **クライアントストレージ**:
  - `sessionStorage`: 現在の編集状態
  - `localStorage`: 要約履歴、選択した要約スタイル、選択した言語モデル

## ✒️テストケースの記述項目

### 1. 記述項目

- **No**: テストケース通し番号
- **大項目**: 画面名または対象レイヤー
- **中項目**: 対象機能
- **種別**: 区分（正常系、異常系、境界値）
- **事前条件**: テスト前の初期データ状態
- **操作手順**: テスト実施者が行う操作手順
- **期待値**: 期待される動作
- **判定**: 検証結果の記録（`OK` / `NG` / `-`）

### 2. 種別について

- **正常系**: 一般的な入力・操作で仕様通り正しく動作する
- **異常系**: 未入力、Ollamaの応答なし、デバイス権限拒否、ファイル形式不正などを適切にハンドリングして安全に復帰させる
- **境界値**: 空白文字、100MB超過ファイル、特殊記号・XSSコード、最大文字数、最大保持件数（100件）などの限界値で破綻しない
